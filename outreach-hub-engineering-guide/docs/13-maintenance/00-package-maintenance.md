    # Package Maintenance

    Monthly or before significant work:

- review Next.js security releases;
- review MCP SDK release notes/spec compatibility;
- run dependency audit;
- update patch/minor versions after CI passes;
- review deprecated MUI/Next APIs;
- remove unused packages.

Major framework upgrades require a dedicated branch/ADR note and regression suite.

Never leave duplicate old/new package APIs indefinitely after migration.
