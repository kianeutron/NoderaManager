    # Data Integrity Checks

    Provide admin diagnostics that can run manually:

- people sharing exact normalized email/LinkedIn identity;
- organizations sharing canonical domain;
- orphaned prospects/links;
- outreach missing person/org/prospect context where required;
- duplicate external message IDs;
- pending Blob uploads older than threshold;
- document metadata with missing Blob;
- Blob objects without metadata where detectable;
- overdue follow-ups;
- invalid route/module relationships.

Diagnostics report first. Automatic destructive repair is not the default.
