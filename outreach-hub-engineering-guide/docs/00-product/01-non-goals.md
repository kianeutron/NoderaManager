    # Non-Goals and Anti-Scope

    V1 is not:

- a mass-email sender;
- a LinkedIn automation/scraping bot;
- a replacement for Gmail or LinkedIn;
- a generic Salesforce clone;
- a marketing automation platform;
- an AI writing product;
- a multi-tenant SaaS;
- a billing/subscription product;
- a social network;
- a background crawler that bypasses platform rules;
- a system that stores passwords for third-party services;
- a vector database project merely because documents exist.

Do not add queues, Kafka, Redis, Kubernetes, microservices, event sourcing, GraphQL, a separate C# backend, or a second API framework without a demonstrated requirement and an ADR.

Do not implement “future enterprise” features that make the personal version slower to ship or harder to reason about.
