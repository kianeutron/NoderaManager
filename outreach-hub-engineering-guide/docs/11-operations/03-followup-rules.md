    # Follow-Up Model

    Follow-ups are explicit tasks, not hidden date fields.

Fields include due_at, status, reason, channel suggestion, prospect, optional outreach/interaction origin, completed_at, dismissed reason.

Do not automatically create endless follow-up sequences. The user or explicit strategy rules decide.

Support “not before” follow-ups for warm future leads and trigger-based notes without pretending the app can monitor external events by itself.
