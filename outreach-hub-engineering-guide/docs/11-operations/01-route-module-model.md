    # Routes and Modules Model

    Routes describe acquisition strategies, not channels.

Examples:

- Agency Overflow
- Recruiters
- Fractional CTO / Consultant Network
- Referral Partners
- Intent Signals
- Vendor Ecosystems
- Communities
- Content / Inbound

Modules refine routes:

Referral Partners -> UX studios, security consultants, cloud consultants, ERP/CRM specialists, product consultants.

Channels (`email`, `linkedin`, `inmail`) are separate dimensions. Do not make “LinkedIn” both a route and a channel unless the route explicitly means a LinkedIn-specific strategic experiment.

This distinction is necessary for analytics: strategy performance is different from channel performance.
