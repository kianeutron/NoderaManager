    # Global Search

    Global search should query typed domains, not dump all records into the browser.

Priority fields:

- person name/email/LinkedIn;
- organization name/domain;
- prospect notes/trigger;
- outreach subject/body snippets;
- document title/tags/extracted text.

Return grouped results with entity type, title, context snippet, stable ID, and match reason.

Use database full-text/trigram indexes where supported. Search must be authorized and bounded.
